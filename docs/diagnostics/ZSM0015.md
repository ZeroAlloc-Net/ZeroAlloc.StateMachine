# ZSM0015 — Duplicate State Machine Part Name

**Severity:** Error

Two `[StateMachinePart]` attributes on the same class share the same `Name`. Part names are the discriminator the generator uses to mangle field and method names (`<Name>Current`, `TryFire<Name>`, `_state_<Name>`). Duplicates would collide.

## Example

```csharp
// ZSM0015: two parts named "Worker"
[StateMachineGroup]
[StateMachinePart<S1, T1>(Name = "Worker", InitialState = S1.Idle)]
[StateMachinePart<S2, T2>(Name = "Worker", InitialState = S2.Off)]
public partial class Bad { }
```

## How to fix

Give each part a distinct `Name`:

```csharp
[StateMachineGroup]
[StateMachinePart<S1, T1>(Name = "Operational", InitialState = S1.Idle)]
[StateMachinePart<S2, T2>(Name = "Connection",  InitialState = S2.Off)]
public partial class Device { }
```

Names follow C# identifier rules — the generator suffixes them onto method names without escaping.

See [Concurrent Parts](../core-concepts/concurrent-parts.md).
