# ZSM0025 — Name Differs Only in Case From Another State Machine

**Severity:** Error

Each `[StateMachine]` and `[StateMachineGroup]` gets a generated file named after its namespace,
containing types and name, such as `MyApp.OrderMachine.g.cs`. Roslyn compares generated file
names ignoring case, so two types whose names differ only in case, such as `MyApp.OrderMachine`
and `MyApp.Ordermachine`, would need the same file.

The type declared first, by file path and then position in the file, is generated. Every later
one gets ZSM0025 and is not generated:

```
'MyApp.Ordermachine' is not generated because its file name 'MyApp.Ordermachine.g.cs' differs only in case from that of 'MyApp.OrderMachine'
```

Every other machine and group in the project is still generated. In earlier versions such a
pair made the generator fail with CS8785, and nothing in the project was generated.

A machine and a group never collide with each other: a group's file ends in `.Group.g.cs`.

## Example

```csharp
// ZSM0025 on Ordermachine
[StateMachine(InitialState = nameof(OrderState.Pending))]
[Transition<OrderState, OrderTrigger>(From = OrderState.Pending, On = OrderTrigger.Pay, To = OrderState.Paid)]
public partial class OrderMachine { }

[StateMachine(InitialState = nameof(OrderState.Pending))]
[Transition<OrderState, OrderTrigger>(From = OrderState.Pending, On = OrderTrigger.Pay, To = OrderState.Paid)]
public partial class Ordermachine { }
```

## How to fix

Rename one of the two types, or move it to another namespace or containing type.
