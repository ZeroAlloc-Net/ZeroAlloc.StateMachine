# ZSM0008 — Composite State Value Not Declared in TState

**Severity:** Error

The `State` value passed to `[CompositeState]` is not a declared member of the parent's `TState` enum. Most often this means the parent transitions and the composite declaration reference different state enum types — they must agree.

## Example

```csharp
public enum Parent  { Idle, Working }
public enum Outside { Foo }  // unrelated enum

// ZSM0008: Outside.Foo is not a member of Parent
[StateMachine(InitialState = nameof(Parent.Idle))]
[Transition<Parent, Trig>(From = Parent.Idle, On = Trig.Start, To = Parent.Working)]
[CompositeState<Outside>(State = Outside.Foo, SubMachine = typeof(WorkFsm))]
public partial class Outer { }
```

## How to fix

Use the parent's own state enum:

```csharp
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(WorkFsm))]
```
