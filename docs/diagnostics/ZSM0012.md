# ZSM0012 — Timeout Transition Requires Concurrent Mode

**Severity:** Error

A `[Transition(... AfterMs = N)]` was declared on a class that is neither `[StateMachine(Concurrent = true)]` nor a `[StateMachineGroup]` (whose parts are implicitly concurrent). Timed edges fire from a `Timer` callback on a thread-pool thread; their CAS-based race safety only holds when the transition path is concurrent.

## Example

```csharp
// ZSM0012: AfterMs on a non-concurrent machine
[StateMachine(InitialState = nameof(S.Idle))]
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 5000)]
public partial class Watchdog { }
```

## How to fix

Either set `Concurrent = true` on the `[StateMachine]`:

```csharp
[StateMachine(InitialState = nameof(S.Idle), Concurrent = true)]
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 5000)]
public partial class Watchdog { }
```

Or move the edge into a `[StateMachineGroup]` part:

```csharp
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
[Transition<S, T>(Part = "Main", From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 5000)]
public partial class Watchdog { }
```

See [Timeout Transitions](../core-concepts/timeout-transitions.md).
