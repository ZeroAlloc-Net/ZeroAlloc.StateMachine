# ZSM0014 — StateMachine and StateMachineGroup Are Mutually Exclusive

**Severity:** Error

A class is annotated with **both** `[StateMachine]` and `[StateMachineGroup]`. These describe two different shapes: `[StateMachine]` says "this class is a single FSM with one state field", while `[StateMachineGroup]` says "this class hosts multiple independent FSMs declared by `[StateMachinePart]`". A class can be one or the other, not both.

## Example

```csharp
// ZSM0014: both top-level attributes declared
[StateMachine(InitialState = nameof(S.Idle))]
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
public partial class Bad { }
```

## How to fix

Pick one.

- For a single FSM, keep `[StateMachine]` and remove `[StateMachineGroup]` plus every `[StateMachinePart]`.
- For multiple parts, remove `[StateMachine]` and keep `[StateMachineGroup]` plus the `[StateMachinePart]` declarations.

See [Concurrent Parts](../core-concepts/concurrent-parts.md).
