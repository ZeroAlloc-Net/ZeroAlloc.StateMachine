# ZSM0010 — History State Without Composite

**Severity:** Error

A `[HistoryState(State = X)]` is declared but no `[CompositeState(State = X, ...)]` exists on the same class. History only has meaning for composite states — there is no sub-FSM to remember without one.

## Example

```csharp
// ZSM0010: HistoryState for Parent.Working but no matching CompositeState
[StateMachine(InitialState = nameof(Parent.Idle))]
[Transition<Parent, Trig>(From = Parent.Idle, On = Trig.Start, To = Parent.Working)]
[HistoryState<Parent>(State = Parent.Working)]
public partial class Outer { }
```

## How to fix

Add the matching `[CompositeState]`, or remove the `[HistoryState]`:

```csharp
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(WorkFsm))]
[HistoryState<Parent>(State = Parent.Working)]
public partial class Outer { }
```

See [Composite States — Shallow history](../core-concepts/composite-states.md#shallow-history-with-historystate).
