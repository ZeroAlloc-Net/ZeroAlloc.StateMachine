# ZSM0028 — Restore Is Not Generated, Conflicting Member

**Severity:** Info

The generator emits `public static T Restore(TState state)`, and `Restore(TState, TSubState)`
for a composite state, see [Persistence](../core-concepts/persistence.md). The type already
declares a member named `Restore` that would conflict with it: one that is not a method, or a
method whose first parameter is the state type and that has one or two parameters. The generator
emits no `Restore` and leaves your member alone.

```
'OrderMachine' gets no generated Restore method because it already declares a member named 'Restore' that conflicts with it
```

It is reported at your member. The machine itself is still generated, and the diagnostic is
informational so that a type that compiled before `Restore` existed keeps compiling.

A `Restore` method with other parameters, such as `Restore(string json)`, does not conflict.

## Example

```csharp
// ZSM0028
public partial class OrderMachine
{
    public static OrderMachine Restore(OrderState state) => ...;
}
```

## How to fix

Rename your member to get the generated `Restore`, or keep yours and ignore the diagnostic.
