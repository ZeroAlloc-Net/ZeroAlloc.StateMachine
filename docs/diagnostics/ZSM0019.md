# ZSM0019 — Incompatible User-Supplied Dispose

**Severity:** Error

The class declares its own `Dispose` member, but the generator already owns
`Dispose` on any class with at least one timed edge. The generator
unconditionally emits `public void Dispose()` (disposing every timer field
and calling `GC.SuppressFinalize(this)`) and there is no escape hatch — no
`partial void` hook, no virtual extension point. Any user-declared
`Dispose` either has the wrong signature (caught by this diagnostic) or
collides with the generated one (caught by `CS0111`). Either way, the
build fails.

## Example

```csharp
// ZSM0019: user-supplied Dispose conflicts with the generator
[StateMachine(InitialState = nameof(S.Idle), Concurrent = true)]
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 5000)]
public partial class Watchdog
{
    public void Dispose(bool disposing) { /* ... */ }
}
```

## How to fix

Remove the user-supplied `Dispose` and let the generator emit it in full:

```csharp
[StateMachine(InitialState = nameof(S.Idle), Concurrent = true)]
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 5000)]
public partial class Watchdog { }   // generator emits public void Dispose()
```

If you need to run additional cleanup beyond timer disposal, put it in a
separate method and call it explicitly — do **not** try to hook it into
`Dispose`:

```csharp
public partial class Watchdog
{
    public void Shutdown()
    {
        // ... your cleanup ...
    }
}

// Caller:
using var w = new Watchdog();
try { /* ... */ }
finally { w.Shutdown(); }   // explicit; runs before Dispose() at end of using
```

See [Timeout Transitions — Dispose contract](../core-concepts/timeout-transitions.md#dispose-contract).
