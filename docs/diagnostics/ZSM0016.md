# ZSM0016 — Transition Part Mismatch

**Severity:** Error

A `[Transition(... Part = "X")]` references a part `Name` that no `[StateMachinePart]` on the class declares, OR a `[Transition]` inside a `[StateMachineGroup]` class omits the `Part` property entirely. Every transition in a group must route to exactly one declared part.

## Example

```csharp
// ZSM0016: Part = "Typo" — no such part
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
[Transition<S, T>(Part = "Typo", From = S.Idle, On = T.Go, To = S.Done)]
public partial class Bad1 { }

// ZSM0016: Part missing on a transition inside a group
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
[Transition<S, T>(From = S.Idle, On = T.Go, To = S.Done)]
public partial class Bad2 { }
```

## How to fix

Set `Part` to a declared part name:

```csharp
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
[Transition<S, T>(Part = "Main", From = S.Idle, On = T.Go, To = S.Done)]
public partial class Good { }
```

The `Part` property is optional only on a single-machine `[StateMachine]` class. Inside a group it is required.

See [Concurrent Parts](../core-concepts/concurrent-parts.md).
