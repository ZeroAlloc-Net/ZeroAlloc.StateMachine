# ZSM0003 — Single-Use Trigger

**Severity:** Warning

A trigger appears in exactly one transition, and its name is close to a trigger that appears in several. That is what a typo looks like: the real trigger is used throughout the machine, and the misspelled one shows up once.

The names are compared case-insensitively, counting inserted, deleted, replaced and swapped adjacent characters as one edit each. A name counts as close when it is within two edits of a reused trigger, or within one edit when either name is shorter than five characters. The message names the trigger you probably meant.

A single-use trigger with a distinct name is not reported. In the canonical circuit breaker, `Trip` is used twice while `Probe` and `Reset` are used once each, because each state has its own exit event:

```csharp
// No ZSM0003: Probe and Reset are not close to Trip
[Transition<CbState, CbTrigger>(From = CbState.Closed,   On = CbTrigger.Trip,  To = CbState.Open)]
[Transition<CbState, CbTrigger>(From = CbState.Open,     On = CbTrigger.Probe, To = CbState.HalfOpen)]
[Transition<CbState, CbTrigger>(From = CbState.HalfOpen, On = CbTrigger.Reset, To = CbState.Closed)]
[Transition<CbState, CbTrigger>(From = CbState.HalfOpen, On = CbTrigger.Trip,  To = CbState.Open)]
```

## Example

```csharp
public enum S { A, B, C }
public enum R { Advance, Advnace }

// ZSM0003: Trigger 'Advnace' on 'MyMachine' is used once; did you mean 'Advance'?
[StateMachine(InitialState = nameof(S.A))]
[Transition<S, R>(From = S.A, On = R.Advance, To = S.B)]
[Transition<S, R>(From = S.B, On = R.Advance, To = S.C)]
[Transition<S, R>(From = S.C, On = R.Advnace, To = S.A)]
public partial class MyMachine { }
```

## How to fix

Use the trigger the message suggests, here `R.Advance`, and remove the misspelled enum member.

If the two triggers really are different events, give the single-use trigger a name that is clearly different from the reused one, for example `Restart` rather than `Advances`. Names that differ by a letter or two are easy to mix up when the machine is read or called.
