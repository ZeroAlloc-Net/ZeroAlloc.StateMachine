# ZSM0013 — AfterMs Must Be Positive

**Severity:** Error

A `[Transition(... AfterMs = N)]` was declared with `N <= 0`. `AfterMs` is a delay in milliseconds; zero or negative values have no meaningful interpretation (zero would fire on the same tick as entry, negative is nonsense for `System.Threading.Timer`).

## Example

```csharp
// ZSM0013: AfterMs is zero
[StateMachine(InitialState = nameof(S.Idle), Concurrent = true)]
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 0)]
public partial class Bad { }
```

## How to fix

Set `AfterMs` to a positive integer:

```csharp
[Transition<S, T>(From = S.Idle, On = T.Tick, To = S.Done, AfterMs = 1)]
```

If you intended a non-timed edge, remove the `AfterMs` property entirely. Its absence (the default) produces a regular synchronous transition.

See [Timeout Transitions](../core-concepts/timeout-transitions.md).
