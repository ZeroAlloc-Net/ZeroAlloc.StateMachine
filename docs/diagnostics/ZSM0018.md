# ZSM0018 — Composite State Inside a Group

**Severity:** Error

A `[CompositeState]` was declared on a `[StateMachineGroup]` class. Parts inside a group are always concurrent, and composite states are incompatible with concurrent dispatch (see [ZSM0005](ZSM0005.md)) — a composite transition cannot be made atomic with a single CAS over a part's state field.

## Example

```csharp
// ZSM0018: composite inside a group
[StateMachineGroup]
[StateMachinePart<P, T>(Name = "Main", InitialState = P.Idle)]
[CompositeState<P>(State = P.Working, SubMachine = typeof(WorkFsm))]
public partial class Bad { }
```

## How to fix

- **Flatten the sub-machine into the part's state enum.** Encode the sub-states as additional members of the part's `TState`.
- **Move the composite to a standalone `[StateMachine]` class** outside the group. Composite states require non-concurrent dispatch.

See [Concurrent Parts](../core-concepts/concurrent-parts.md) and [Composite States — Concurrent mode](../core-concepts/composite-states.md#concurrent-mode).
