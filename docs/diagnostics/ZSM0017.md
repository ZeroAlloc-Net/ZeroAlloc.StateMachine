# ZSM0017 — Group Has No Parts

**Severity:** Error

A class is annotated `[StateMachineGroup]` but declares zero `[StateMachinePart]` attributes. A group with no parts has nothing to generate — no state fields, no `TryFire<Name>` methods.

## Example

```csharp
// ZSM0017: group with no parts
[StateMachineGroup]
public partial class Empty { }
```

## How to fix

Add at least one `[StateMachinePart]`:

```csharp
[StateMachineGroup]
[StateMachinePart<S, T>(Name = "Main", InitialState = S.Idle)]
public partial class Empty { }
```

If you actually wanted a single FSM, replace `[StateMachineGroup]` with `[StateMachine]` instead.

See [Concurrent Parts](../core-concepts/concurrent-parts.md).
