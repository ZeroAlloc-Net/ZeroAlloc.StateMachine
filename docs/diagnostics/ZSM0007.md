# ZSM0007 — Sub-Machine Trigger Type Mismatch

**Severity:** Error

The sub-machine declared in a `[CompositeState]` uses a different `TTrigger` enum than the parent. A hierarchy must share a single trigger type so that `TryFire` can pass identical trigger values across levels — the parent dispatches to the sub-FSM's `TryFire(TTrigger)` with the value it received.

The sub-machine's `TState` is independent and can be any enum; only `TTrigger` must match.

## Example

```csharp
public enum ParentTrig { Start, Stop }
public enum SubTrig    { Go, Halt }  // different enum

[StateMachine(InitialState = nameof(SubState.A))]
[Transition<SubState, SubTrig>(From = SubState.A, On = SubTrig.Go, To = SubState.B)]
[Terminal<SubState>(State = SubState.B)]
public partial class SubFsm { }

// ZSM0007: SubFsm uses SubTrig but Outer uses ParentTrig
[StateMachine(InitialState = nameof(Parent.Idle))]
[Transition<Parent, ParentTrig>(From = Parent.Idle, On = ParentTrig.Start, To = Parent.Working)]
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(SubFsm))]
public partial class Outer { }
```

## How to fix

Use the parent's trigger enum throughout the sub-machine:

```csharp
[StateMachine(InitialState = nameof(SubState.A))]
[Transition<SubState, ParentTrig>(From = SubState.A, On = ParentTrig.Start, To = SubState.B)]
[Terminal<SubState>(State = SubState.B)]
public partial class SubFsm { }
```

If two genuinely different trigger vocabularies exist, the two machines are not in a parent/child relationship and should not be composed. Adapt at the call site instead.
