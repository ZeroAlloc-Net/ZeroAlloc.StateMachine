# ZSM0009 — Duplicate Composite State

**Severity:** Error

The same parent state is declared composite in more than one `[CompositeState]` attribute. Each parent state can have at most one sub-machine — declaring two sub-machines for the same state would be ambiguous at runtime.

## Example

```csharp
// ZSM0009: Parent.Working has two sub-machines
[StateMachine(InitialState = nameof(Parent.Idle))]
[Transition<Parent, Trig>(From = Parent.Idle, On = Trig.Start, To = Parent.Working)]
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(FsmA))]
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(FsmB))]
public partial class Outer { }
```

## How to fix

Keep only one `[CompositeState]` per state. If you need to switch between two sub-FSMs at runtime, that is a transition between two distinct parent states, not two sub-machines on the same state:

```csharp
[Transition<Parent, Trig>(From = Parent.Idle,    On = Trig.StartA, To = Parent.WorkingA)]
[Transition<Parent, Trig>(From = Parent.Idle,    On = Trig.StartB, To = Parent.WorkingB)]
[CompositeState<Parent>(State = Parent.WorkingA, SubMachine = typeof(FsmA))]
[CompositeState<Parent>(State = Parent.WorkingB, SubMachine = typeof(FsmB))]
```
