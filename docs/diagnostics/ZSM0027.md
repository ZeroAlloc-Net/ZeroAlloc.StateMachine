# ZSM0027 — Restore Is Not Generated, No Parameterless Constructor

**Severity:** Info

The generated `public static T Restore(TState state)` creates the machine with `new T()` and
then sets its state, see [Persistence](../core-concepts/persistence.md). It is not generated
when that would not compile:

- a class declares constructors, a primary constructor included, but none without parameters;
- the class is abstract;
- a machine with timed transitions has a primary constructor, or a base class without an
  accessible parameterless constructor. `Restore` builds it through a generated private
  constructor that arms no timer, and that constructor cannot chain to constructors whose
  arguments only you know;
- the type is a `[StateMachineGroup]` declared as a struct;
- a struct has a primary constructor and no parameterless constructor, so `new T()` would skip
  the field initializers.

```
'OrderMachine' gets no generated Restore method because it declares constructors but no parameterless one
```

The machine itself is still generated, and the diagnostic is informational so that a type that
compiled before `Restore` existed keeps compiling.

## Example

```csharp
// ZSM0027
[StateMachine(InitialState = nameof(OrderState.New))]
[Transition<OrderState, OrderTrigger>(From = OrderState.New, On = OrderTrigger.Pay, To = OrderState.Paid)]
public partial class OrderMachine
{
    public OrderMachine(ILogger logger) { }
}
```

## How to fix

Add a parameterless constructor, which may be private, to get `Restore`:

```csharp
public partial class OrderMachine
{
    public OrderMachine() { }
    public OrderMachine(ILogger logger) { }
}
```

On a machine with timed transitions, a constructor you declare must call `HookConstructor()`,
see [ZSM0021](ZSM0021.md). Ignore the diagnostic if you do not need `Restore`.
