# ZSM0006 — Sub-Machine Is Not a [StateMachine]

**Severity:** Error

The `SubMachine` type referenced in a `[CompositeState]` declaration is not a `partial class` annotated with `[StateMachine]`. Composite states delegate `TryFire` to the sub-machine's generated dispatcher; a type without one cannot participate.

## Example

```csharp
public class PlainClass { }  // no [StateMachine] attribute

// ZSM0006: PlainClass is not a [StateMachine]
[StateMachine(InitialState = nameof(Parent.Idle))]
[Transition<Parent, Trig>(From = Parent.Idle, On = Trig.Start, To = Parent.Working)]
[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(PlainClass))]
public partial class Outer { }
```

## How to fix

Make the sub-machine type a proper `[StateMachine]` partial class:

```csharp
[StateMachine(InitialState = nameof(WorkStep.Init))]
[Transition<WorkStep, Trig>(From = WorkStep.Init, On = Trig.Step, To = WorkStep.Done)]
[Terminal<WorkStep>(State = WorkStep.Done)]
public partial class WorkFsm { }

[CompositeState<Parent>(State = Parent.Working, SubMachine = typeof(WorkFsm))]  // now valid
```
